Reference → Countries / Periods / Currencies/Довідники → Країни / Періоди / Валюти.

Країни

  • Continent/Континент — де країна показується в дереві.
  • Exists (not an extinct state)/Існує (не зникла держава) — знято: країна показується в Extinct states/Зниклі держави.
  • Part of/Входить у — країна показується в дереві всередині іншої країни (наприклад, Prussia у Germany); порожньо — окремо. Те саме робиться перетягуванням у дереві, див. Головне вікно.
  • Reference → Place countries on continents/Довідники → Розставити країни по континентах — для країн у No continent/Без континенту (наприклад, імпортованих з Numista попередньою версією): програма показує, яка країна на який континент піде (за емітентом Numista), і переносить їх після підтвердження. Країни не об'єднуються й не перейменовуються.
  • Numista issuer/Емітент Numista — код емітента Numista для пошуку монет цієї країни. Заповнюється автоматично; змінюйте його, лише якщо монети країни не знаходяться.

Періоди та валюти

Назви можна виправити; запис можна видалити, лише якщо жодна монета його не використовує.

Імпорт з uCoin зіставляє країни за назвою: після перейменування стара назва створиться знову при наступному імпорті.
