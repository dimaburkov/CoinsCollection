Фото

Фото примірника і фото типу

  • Фото примірника — ваш власний знімок вашого примірника.
  • Фото типу спільне для всіх примірників монети. У картці позначте Save as coin type photo/Зберегти як фото типу перед додаванням.
  • Спершу показується фото примірника; без нього — фото типу з позначкою фото типу.

Додавання фото

У картці монети: File.../Файл... (JPEG, PNG, BMP, GIF, TIFF), Paste/Вставити або перетягніть файл на рамку. Фото зменшуються до 1200 px і зберігаються як JPEG у Photos\.

Фото з Numista

Коли монету пов'язано з Numista, зображення аверсу й реверсу типу завантажуються автоматично як фото типу (зв'язок, оновлення даних каталогу). Ваше власне фото типу ніколи не замінюється. Автор зображення показується у вікні перегляду: Photo: <автор> / Numista.

Перегляд

Подвійне клацання по фото в подробицях. Коліщатко миші — масштаб, перетягування — зсув, ←/→ або Пробіл — інша сторона, 0 або Home — за розміром вікна, Esc — закрити.
