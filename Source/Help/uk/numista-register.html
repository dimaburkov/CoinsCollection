Numista: реєстрація та ключ API

Numista безкоштовна. Програма працює з Numista через офіційний API Numista: кожен користувач має власний безкоштовний ключ (2000 запитів на місяць — досить для колекції з кількох сотень монет). Реєстрація займає близько 5 хвилин.

1. Зареєструйтеся на Numista

  1. Відкрийте en.numista.com і натисніть Sign up (сайт можна перемкнути на іншу мову внизу сторінки).
  2. Введіть ім'я користувача, e-mail і пароль.
  3. Підтвердіть e-mail: відкрийте лист від Numista й перейдіть за посиланням.

2. Отримайте ключ API

  1. Увійшовши на Numista, відкрийте en.numista.com/api/api_key.php.
  2. Заповніть коротку форму (англійською). В описі використання можна написати: personal management of my coin collection with the Coins Collection program.
  3. Скопіюйте ключ, який видасть Numista. Нікому його не показуйте — як пароль.

3. Введіть ключ у програмі

  1. Numista → Connect / Settings/Numista → Підключення / налаштування, вставте ключ.
  2. Натисніть Check connection/Перевірити підключення: програма перевірить ключ і завантажить списки емітентів і каталогів Numista (один раз).

Готово. Далі: З чого почати — імпортуйте свою колекцію Numista або пов'яжіть монети з uCoin. Про запити й місячну квоту: Numista: підключення та запити.
