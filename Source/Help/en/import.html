Import from uCoin

Export from uCoin

  1. On the uCoin website switch the site language to English (language selector at the top or bottom of the page).
  2. Open your collection and export it to Excel (.xlsx). Save the file on your computer.
The export must be in English. In an export made in another language (Russian, Ukrainian…) uCoin translates the column headers and the names of countries, periods, currencies and denominations — the program does not accept such a file: countries would not get into continents and Numista search would not work. The program recognizes such a file, explains how to fix it and does not change the collection.

Import

  1. File → Import collection from uCoin (.xlsx)... (or the Import button) and choose the file.
  2. The program shows how many rows were read and which rows have errors (skipped). Confirm the import.
  3. The current collection is replaced by the file. A backup copy of the database is made first: Db\…before-import-<date>.bak.

What is kept on a repeated import

You can import a newer uCoin export at any time. For coins that are in the new file, the program keeps:

  • Numista links (#Numista, issue, rarity index, Numista search phrase) and the ✓ of uploaded items;
  • photos of coins and items.

The result shows how many links and photos were kept and lost. Photos of coins that are no longer in the file are moved to Photos\_before-import-<date>\.

Countries are matched by name. If you rename a country in Reference lists, the old uCoin name will appear again after the next import.

Swap list from uCoin

On uCoin open your swap list and export it to Excel (the site in English), then File → Import swap list from uCoin (.xlsx).... The program checks the file by its columns: a collection export chosen here (or a swap list chosen in the collection import) is not imported, the message names the right command.

  • The coins go to the node For swap; the collection does not change. A coin that is also in the collection is the same coin (the column Swap shows it); a coin that is only for swap is a new coin.
  • The swap export has no period: it is taken from a coin of the same country with the same catalogue number, otherwise it stays empty (choose it in the coin card). A historical state that uCoin writes as the country (German Empire) goes to the country and period from your collection (Germany / German Empire).
  • Information, reserve and the private note go to the item comment.
  • A repeated import updates the swap list: new items are added, changed ones are updated; for items that are not in the file the program asks whether to remove them from the swap list.
  • A coin for swap gets the Numista link at once, without requests, from a linked coin of the same country with the same catalogue number: the type, the issue (if it is already known for that year) and the catalogue pictures. The others — Auto-link as usual.
  • Upload to your Numista swap list — Numista: upload, Swap list.

An item can be moved between the collection and the swap list in the coin card (List). In the node For swap the commands Add and Add from sample... add a coin for swap. A repeated import of the collection does not change the swap list.

Import from your Numista collection

Coins that you added on Numista yourself and that are not in uCoin (for example ancient coins) can be imported too: Numista → Import from my Numista collection.

  1. The window lists the items of your Numista collection that are not in the program yet.
  2. Filter by Issuer (for example Roman Empire), check the items and press Import.
  3. For each item the program creates the coin (country by the Numista issuer, period by the ruler, currency, denomination, years, catalogue number) and your item (grade, quantity, purchase date, comment), links it with Numista (✓) and loads the type details and photos — the type photos and your own photos of the item on Numista.

A new country (for example Roman Empire) appears under No continent: set its continent and “extinct” in Reference lists. Years can be a range (174–179) and before Christ (44 BC). A price in another currency than UAH is added to the comment.

The coin is already in the program (from uCoin)

The column In the program shows what happens to each item:

  • Link to … — the same coin is already in the program: it is linked with the item (✓, details, photos), no second coin. It is found by the Numista type or by the catalogue number with the year and country; a number without the sub-number also counts (C# 118 in uCoin = C# 118.3 on Numista).
  • new coin — a new coin is added. If the coin is in fact in the program (other number, other name), select the row and press Coin in the program... (or double-click the column In the program) and choose it: coins of the same number come first, then of the same denomination. The first line, new coin, undoes the choice.
  • ambiguous — several coins fit: choose one the same way, otherwise the item is skipped.
Coins imported from Numista are kept when you import a uCoin file again.
