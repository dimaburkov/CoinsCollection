Reference → Countries / Periods / Currencies.

Countries

  • Continent — where the country is shown in the tree.
  • Exists (not an extinct state) — unchecked: the country is shown under Extinct states.
  • Numista issuer — the Numista issuer code used to search coins of this country. It is filled automatically; change it only if coins of the country are not found.

Periods and currencies

Names can be corrected; an entry can be deleted only if no coin uses it.

The uCoin import matches countries by name: after renaming, the old name is created again on the next import.
