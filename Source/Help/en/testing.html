What to check (for testers)

Thank you for testing Coins Collection! Go through the parts that fit your collection — you do not need all of them. After each step it says what you should see. Something different — Help → Report a problem (the letter already contains the version and Windows; add a screenshot).

1. Installation and first start

  1. Run CoinsCollection-Setup-…exe; the installer is not signed — in the browser Keep, in SmartScreen More info → Run anyway. Expected: installed without administrator rights.
  2. Start the program. Expected: an empty collection, the interface language as chosen in the installer (Settings → Language switches it).

2. Import from uCoin

  1. On uCoin switch the site to English and export your collection to Excel (Import from uCoin).
  2. File → Import collection from uCoin (.xlsx).... Expected: the number of rows and errors, then the countries in the tree on the left, the coins in the list.
  3. Try an export made in Russian or Ukrainian. Expected: a message that the file is not in English and how to fix it; the collection is not changed.

3. Numista: key and linking

  1. Get a free API key and enter it (Numista: registration and API key), Check connection. Expected: “Connected as Numista user …”.
  2. Check 10–20 coins of one country → Auto-link. Expected: most coins get a #Numista number, the result window says how many are linked and how many need checking.
  3. A coin that was not linked → right-click → Link manually. Expected: the type list with a search phrase; you can change the phrase, search again and link.

4. Your Numista collection (Roman denarii and other ancient coins)

  1. Numista → Import from my Numista collection, choose the issuer (for example Roman Empire). Expected: your items with years and grades; after the import — coins with catalogue pictures.
  2. Write the rarity index into the private comment of an item on Numista, then Read rarity index. Expected: the number in the Rarity column; sorting by this column puts the rarest coins first.
  3. Import your Numista collection when the coins are already in the program from uCoin. Expected: the column In program shows Link to … for coins found in the program; for a new coin that is in fact in the program — Coin in the program..., choose it; no second coin is added.

5. Photos

  1. Open a coin card (double-click) and drag your photos of the obverse and reverse into the right column. Expected: your photos next to the catalogue pictures.
  2. In the coin details press ⇄. Expected: switching between your photo and the catalogue picture.

6. Numista prices

  1. Numista settings → What to load from Numista → Numista prices (estimate by condition).
  2. A coin with a chosen issue → right-click → Load Numista prices. Expected: the price for the condition of the coin in the column, all conditions in the details.
  3. A linked coin → right-click → Auction sales.... Expected: past auction sales of the issue (or of the whole type) with prices in your currency, the summary “from — to, median”, links to the lots.

7. Backup

  1. File → Backup collection. Expected: one .zip file.
  2. (On a test copy only.) File → Restore from backup. Expected: the collection and photos as in the backup.

8. The coin list

  1. Right-click a column header → Columns: hide a column, turn on Obverse and Reverse. Expected: small photos of the coins in the list; Row height makes them larger.
  2. Drag a column header to another place; change the window size, the width of the tree and of a column. Restart the program. Expected: everything as you left it.

What to send with a problem

  • What you did and what happened — step by step; a screenshot of the message.
  • For an import error — the export file (it contains only your collection).
  • For a Numista problem — the coin (country, denomination, year, number) and the #Numista you expected.
