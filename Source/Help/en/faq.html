Questions and problems

A coin is not found on Numista or the wrong types are offered

Edit the search phrase in the type list and search again — Numista: linking coins. Check the catalogue number in the coin card (KM#, Y#, C#). Coins with a uCoin number (UC#) are searched by phrase — fill in the subject.

The monthly request quota is almost used

Work with checked coins (one request per run for upload and rarity), turn off Also load type details and photos in auto-link and load the details later.

“Unable to write … CoinsCollection.ini”

The file is open in an editor that locks it. Close the editor and repeat the command.

Photos from Numista were not loaded

Check the internet connection and run Update catalogue data for the checked coins again.

Backup and restore

File → Backup collection saves one .zip file with the database, all photos and the settings. Keep it on another disk or in the cloud. The program reminds you if there was no backup for 30 days.

File → Restore from backup replaces the collection and photos with the backup. The current data is kept (Db\…before-restore-<time>.bak, Photos\_before-restore-<time>\). Settings of this computer are not changed.

Besides, the program makes automatic copies of the database (Db\*.bak) before every database upgrade and every import.
