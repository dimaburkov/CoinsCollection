Installation and settings

Installation and update

  1. Run CoinsCollection-Setup-<version>.exe. Administrator rights are not needed.
  2. If Windows SmartScreen warns about an unknown publisher, press More info → Run anyway.
  3. The program is installed for the current user into %LOCALAPPDATA%\Programs\CoinsCollection (you can choose another folder, but not inside Program Files: the program keeps its data in its own folder).

Update: install the new version over the old one — your collection, photos and settings stay; the database is upgraded automatically (with a backup copy).
Removal: the program files are removed, your collection, photos and settings stay in the folder.

First steps

Your way depends on where your collection is now — uCoin, Numista, both or neither: Where to start.

Language

Settings → Language — English or Ukrainian. English is used by default.

Where the data is

Folder / file next to the programWhat is inside
Db\The collection database and its automatic backup copies (*.bak): before every database upgrade and before every import.
Photos\Coin photos (JPEG). The database keeps only the file names.
Numista\Cached Numista answers: a coin type that was found once is never requested again.
CoinsCollection.iniSettings: language, your Numista API key, request counter for the month.
To move the collection to another computer, make a backup (Backup and restore) and restore it there.
