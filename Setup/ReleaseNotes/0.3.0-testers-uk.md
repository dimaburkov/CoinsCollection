Друзі, шукаю 3–5 людей, які допоможуть перевірити безкоштовну програму для обліку монет — **Coins Collection** (Windows 10 / 11).

**Що вміє:**
- імпортує вашу колекцію з **uCoin** (файл експорту Excel);
- сама знаходить монети в каталозі **Numista** — тираж, вага, метал, правитель і зображення;
- **ваші фото поруч із фото з каталогу** — зручно порівняти стерту монету з гарним екземпляром;
- для денаріїв та інших античних монет: імпорт вашої колекції з Numista, **сортування за рідкістю**;
- за бажанням — **ціни Numista** за станом монети;
- резервна копія всієї колекції одним файлом.

**Що потрібно:** комп'ютер з Windows; для Numista — безкоштовна реєстрація і ключ API (у довідці є покрокова інструкція з картинками, ~5 хвилин).

**Завантажити:** https://github.com/dimaburkov/CoinsCollection/releases/tag/v0.3.0 (файл `CoinsCollection-Setup-0.3.0.exe` унизу, у розділі *Assets*)

**Що перевірити:** у програмі — Довідка → «Що перевірити (для тестувальників)», або F1. Не обов'язково все: пройдіть те, що стосується вашої колекції.

**Знайшли проблему або є ідея:** у програмі **Довідка → Повідомити про проблему** — лист уже містить версію програми та Windows, додайте знімок екрана. Або пишіть у групу підтримки в Telegram: https://t.me/CoinsCol чи на progua@ukr.net.

Програма безкоштовна, працює через офіційний API Numista з дозволу Numista; ваша колекція зберігається лише на вашому комп'ютері.
