Your coin collection on your computer — and an easy way to move it from **uCoin** to **Numista**. This version lets you arrange countries in the tree the way you like (for example *Prussia* inside *Germany*) and shows your own photos and the Numista catalogue pictures in separate columns of the list. Questions and problems: **Help → Report a problem** in the program or the support group in Telegram: https://t.me/CoinsCol.

### Download

**`CoinsCollection-Setup-0.6.0.exe`** (below, in *Assets*) — Windows 10 / 11, no administrator rights needed. **Install it over 0.5.0** — your collection, photos and settings stay; the database is upgraded automatically (a copy `coins.v13.bak` is made first).

The installer is not digitally signed: if the browser says *“not commonly downloaded”*, choose **Keep**; if Windows SmartScreen appears, choose **More info → Run anyway**.

SHA-256: `CB241DED8F77C3CE5348F683855A01A97015F0172C5FF61E678C99B5B365E5FE`

### What is new since 0.5.0

- **Nested countries:** drag a country in the tree onto another country — for example *Prussia*, *Germany - GDR* and *Germany - Third Reich* inside *Germany*; the country node then also shows the coins of the countries inside. Drag a country onto a continent (*Ceylon* under *Asia*) or back onto *No continent* / *Extinct states*. The country keeps its periods, Numista issuer and coins, so a repeated import from uCoin or Numista keeps everything in place. The same is in **Reference → Countries** (the field *Part of*).
- **Photo columns:** *My obverse* / *My reverse* show only your own photos, the new columns *Numista obverse* / *Numista reverse* — the catalogue pictures. Turn on all four to compare your coin with the catalogue right in the list (right-click a column header). If you already used the photo columns, the new ones are turned on too.
- The program name is the same in all languages — **Coins Collection**; the window title shows the version.

Each user uses their own free Numista key (2000 requests per calendar month).

### Українською

**Coins Collection 0.6.0** — ваша колекція монет на комп'ютері та простий спосіб перенести її з uCoin на Numista. У цій версії країни в дереві можна розставити, як вам зручно (наприклад, *Prussia* всередині *Germany*), а ваші фото й зображення з каталогу Numista показуються в окремих колонках списку. Питання та проблеми: **Довідка → Повідомити про проблему** у програмі або група підтримки в Telegram https://t.me/CoinsCol.

Завантажте **`CoinsCollection-Setup-0.6.0.exe`** нижче (*Assets*) і **встановіть поверх 0.5.0** — колекція, фото й налаштування залишаються; база оновлюється автоматично (спочатку робиться копія `coins.v13.bak`). Інсталятор без цифрового підпису: у браузері — **Зберегти**, у SmartScreen — **Детальніше → Однаково запустити**.

**Що нового з 0.5.0**

- **Вкладені країни:** перетягніть країну в дереві на іншу країну — наприклад, *Prussia*, *Germany - GDR* і *Germany - Third Reich* у *Germany*; вузол країни тоді показує й монети вкладених. Перетягніть країну на континент (*Ceylon* в *Asia*) або назад на *Без континенту* / *Зниклі держави*. Країна зберігає свої періоди, емітента Numista й монети, тож повторний імпорт з uCoin чи Numista нічого не зсуває. Те саме — у **Довідники → Країни** (поле *Входить у*).
- **Колонки фото:** *Мій аверс* / *Мій реверс* показують лише ваші фото, нові колонки *Аверс Numista* / *Реверс Numista* — зображення з каталогу. Увімкніть усі чотири, щоб порівнювати свою монету з каталогом просто в списку (праве клацання по заголовку колонки). Якщо ви вже користувалися колонками фото, нові ввімкнуться теж.
- Назва програми однакова в усіх мовах — **Coins Collection**; у заголовку вікна — версія.

Ключ API Numista — безкоштовно на https://en.numista.com/api/api_key.php
