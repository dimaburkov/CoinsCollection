## Coins Collection 0.3.0

Your coin collection on your computer — and an easy way to move it from **uCoin** to **Numista**. This version is for the first testers: please tell us what works and what does not (**Help → Report a problem** in the program, or the support group in Telegram: https://t.me/CoinsCol).

### Download

**`CoinsCollection-Setup-0.3.0.exe`** (below, in *Assets*) — Windows 10 / 11, no administrator rights needed. Installing over 0.2.0 keeps your collection; the database is upgraded automatically (a backup copy is made first).

The installer is not digitally signed: if the browser says *“not commonly downloaded”*, choose **Keep**; if Windows SmartScreen appears, choose **More info → Run anyway**.

SHA-256: `<after the build>`

### What is new since 0.2.0

- **Better automatic linking with Numista:** coins with a uCoin number (UC#) are found by a phrase “country + year + subject”; coins of one type from different years take the type from an already linked coin; search by KM / Y / C number together with the year (coins of the German Empire, Italian and Indian states are found); a type whose years do not include the coin's year is not linked silently.
- **Link manually** always opens the type list — you can edit the search phrase; **Unlink from Numista**, also for items already uploaded (change, delete or keep them on Numista).
- **Your photos next to the catalogue pictures** in the coin card; **⇄** in the coin details switches them.
- **Numista prices** (optional): the estimate for the condition of each coin in UAH, USD or EUR, all conditions in the details, the total in the status bar.
- **Numista settings on tabs:** what to load (details, photos, prices), what to upload (condition, price, date, comment), requests (monthly quota, counter).
- **Add from sample** (Ctrl+Ins): a new coin with the data of the selected one — just change the year.
- **Subject** column when one country is selected; the columns fit into the window.
- The uCoin export must be in English — a file in another language is recognized and explained.
- Help: **Where to start**, **Numista: registration and API key**, **How to link a coin — typical cases**, **What to check (for testers)**.

### First steps

1. uCoin: switch the site to **English**, export your collection to `.xlsx` → **File → Import from uCoin (.xlsx)**.
2. Numista: get your free API key at https://en.numista.com/api/api_key.php → **Numista → Connect / Settings**.
3. **Auto-link** checked coins (or **Link manually**) → **Upload**.

Each user uses their own free Numista key (2000 requests per calendar month).

### Українською

**Coins Collection 0.3.0** — ваша колекція монет на комп'ютері та простий спосіб перенести її з uCoin на Numista. Ця версія — для перших тестувальників: розкажіть, що працює, а що ні (**Довідка → Повідомити про проблему** у програмі).

Завантажте **`CoinsCollection-Setup-0.3.0.exe`** нижче (*Assets*). Встановлення поверх 0.2.0 зберігає колекцію; база оновлюється автоматично (спочатку робиться копія). Інсталятор без цифрового підпису: у браузері — **Зберегти**, у SmartScreen — **Детальніше → Однаково запустити**.

**Що нового з 0.2.0**

- **Краще автоматичне зв'язування з Numista:** монети з номером uCoin (UC#) знаходяться за фразою «країна + рік + сюжет»; монети одного типу різних років беруть тип від уже пов'язаної монети; пошук за номером KM / Y / C разом із роком (знаходяться монети Німецької імперії, італійських та індійських держав); тип, роки якого не включають рік монети, не пов'язується мовчки.
- **Пов'язати вручну** завжди відкриває список типів — фразу пошуку можна змінити; **Відв'язати від Numista**, також для вже вивантажених примірників.
- **Ваші фото поруч із зображеннями з каталогу** в картці монети; **⇄** у подробицях перемикає їх.
- **Ціни Numista** (за бажанням): оцінка для стану кожної монети в UAH, USD або EUR, усі стани — у подробицях, сума — у рядку стану.
- **Налаштування Numista на вкладках:** що завантажувати, що вивантажувати, запити.
- **Додати за зразком** (Ctrl+Ins); колонка **Сюжет**, коли вибрано країну; колонки вміщуються у вікно.
- Експорт з uCoin має бути англійською — файл іншою мовою програма розпізнає і пояснює, що робити.
- Довідка: «З чого почати», «Реєстрація на Numista і ключ API», «Як пов'язати монету — типові випадки», «Що перевірити (для тестувальників)».

Ключ API Numista — безкоштовно на https://en.numista.com/api/api_key.php
