## Coins Collection 0.4.0

Your coin collection on your computer — and an easy way to move it from **uCoin** to **Numista**. This version adds auction sales from Numista and a coin list you can arrange yourself — thanks to the testers for their remarks! Questions and problems: **Help → Report a problem** in the program or the support group in Telegram: https://t.me/CoinsCol.

### Download

**`CoinsCollection-Setup-0.4.0.exe`** (below, in *Assets*) — Windows 10 / 11, no administrator rights needed. **Install it over 0.3.0** — your collection, photos and settings stay; the database is upgraded automatically (a copy `coins.v11.bak` is made first).

The installer is not digitally signed: if the browser says *“not commonly downloaded”*, choose **Keep**; if Windows SmartScreen appears, choose **More info → Run anyway**.

SHA-256: `9087277B707DFB9CF55C33A6611FA983B2460822AA9B9C6DE046441DB91734D4`

### What is new since 0.3.0

- **Auction sales (Numista):** right-click a linked coin → **Auction sales...** (or click the Numista prices row in the details): past sales of the issue or of the whole type with prices in your currency, only your coin's grade if you like, the summary “from — to, median” and links to the lots.
- **Numista title:** the ruler, variety or legend from the Numista type title is shown in gray after the denomination (e.g. *1 Denarius  Crispina (CONCORDIA)*); the full title is in the details, and the search finds it too.
- **Coin list:**
  - choose the columns — right-click a column header;
  - **Obverse** and **Reverse** columns with small photos (your photo, otherwise the catalogue picture), row height normal / medium / large; double-click a photo to open the viewer;
  - drag a column header to move the column;
  - the window size and position (also maximized), the tree width, the details height and the column widths you set are remembered, as well as the sizes of the Numista type, sales, import and photo windows.
- **Photos** in the list, the details, the coin card and the viewer are smooth now — no more “grainy” pictures.
- **Import from your Numista collection:** a number without the sub-number finds the coin (C# 118 = C# 118.3); **Coin in the program...** — choose by hand which coin of the program an item belongs to, instead of adding a second coin.
- Help: the **What to check (for testers)** page lists the new features.

Each user uses their own free Numista key (2000 requests per calendar month).

**Що нового з 0.3.0**

- **Продажі на аукціонах (Numista):** праве клацання по пов'язаній монеті → **Продажі на аукціонах...** (або клацніть рядок цін Numista у подробицях): минулі продажі випуску або всього типу з цінами у вашій валюті, за бажанням — лише для стану вашої монети, підсумок «від — до, медіана», посилання на лоти.
- **Назва Numista:** правитель, різновид чи легенда з назви типу Numista — сірим після номіналу (напр. *1 Denarius  Crispina (CONCORDIA)*); повна назва — у подробицях, пошук знаходить і її.
- **Список монет:**
  - вибір колонок — праве клацання по заголовку колонки;
  - колонки **Аверс** і **Реверс** з мініатюрами (ваше фото, інакше зображення з каталогу), висота рядків — звичайна / середня / велика; подвійне клацання по мініатюрі відкриває перегляд;
  - колонки можна переставляти — перетягніть заголовок;
  - програма запам'ятовує розмір і положення вікна (і розгорнуте), ширину дерева, висоту подробиць і ширини колонок, а також розміри вікон вибору типу Numista, продажів, імпорту й перегляду фото.
- **Фото** у списку, подробицях, картці монети й перегляді — гладкі, без «зерна».
- **Імпорт з вашої колекції Numista:** номер без підномера знаходить монету (C# 118 = C# 118.3); **Монета в програмі...** — вибрати вручну, з якою монетою програми пов'язати предмет, замість другої монети.
- Довідка: на сторінці **Що перевірити (для тестувальників)** — нові можливості.

Ключ API Numista — безкоштовно на https://en.numista.com/api/api_key.php
