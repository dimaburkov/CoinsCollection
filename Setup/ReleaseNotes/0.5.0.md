Your coin collection on your computer — and an easy way to move it from **uCoin** to **Numista**. This version adds your **swap list** and **wish list** from uCoin: the swap list goes to your Numista collection marked for swap, and you see at once which wanted coins you already have. Questions and problems: **Help → Report a problem** in the program or the support group in Telegram: https://t.me/CoinsCol.

### Download

**`CoinsCollection-Setup-0.5.0.exe`** (below, in *Assets*) — Windows 10 / 11, no administrator rights needed. **Install it over 0.4.0** — your collection, photos and settings stay; the database is upgraded automatically (a copy `coins.v12.bak` is made first).

The installer is not digitally signed: if the browser says *“not commonly downloaded”*, choose **Keep**; if Windows SmartScreen appears, choose **More info → Run anyway**.

### What is new since 0.4.0

- **Swap list from uCoin:** **File → Import swap list from uCoin (.xlsx)**. The coins go to the new node **For swap**; the collection does not change. A coin for swap gets the Numista link at once, without requests, from a linked coin with the same catalogue number (type, issue, catalogue pictures). A repeated import updates the list and shows the items that are no longer in the file.
- **Swap list on Numista:** **Upload** for items for swap puts them into your Numista collection marked for swap; the swap note (for example *VF-, 50% of price*) becomes the public comment. Moving an item between the collection and the swap list in the coin card changes the mark on Numista too; import from your Numista collection puts items for swap into **For swap**.
- **Wish list from uCoin:** **File → Import wish list from uCoin (.xlsx)** — the node **Wish list**, year ranges (*2008–2026*), Numista link without requests; a wanted coin that is already in your collection is shown in bold green. Numista has no wish list in its API, so it is not uploaded — the help explains how to add a coin to your Numista wish list on the website.
- **The column Swap:** how many you have for swap, **✓** — uploaded to Numista.
- **Delete checked** (Collection menu and context menu) — for example the whole swap list; items uploaded to Numista can be deleted there too or kept; a backup copy of the database is made first.
- **Columns:** alignment of each column (right-click a header → **Alignment**); Country and Subject are shown as chosen in the Columns menu. The top tree node is now **My collection**.
- Clear buttons in questions (*Import and remove the missing ones*, *Keep them on Numista* …) instead of Yes / No.

Each user uses their own free Numista key (2000 requests per calendar month).

У цій версії — ваші **списки обміну й бажаних** з uCoin: список обміну вивантажується у вашу колекцію на Numista з позначкою обміну, а бажані монети, які вже є в колекції, видно одразу. Завантажте **`CoinsCollection-Setup-0.5.0.exe`** нижче (*Assets*) і **встановіть поверх 0.4.0** — колекція, фото й налаштування залишаються; база оновлюється автоматично (спочатку робиться копія `coins.v12.bak`). Інсталятор без цифрового підпису: у браузері — **Зберегти**, у SmartScreen — **Детальніше → Однаково запустити**.

**Що нового з 0.4.0**

- **Список обміну з uCoin:** **Файл → Імпорт списку обміну з uCoin (.xlsx)**. Монети потрапляють у новий вузол **На обмін**; колекція не змінюється. Монета на обмін одразу, без запитів, отримує зв'язок з Numista від пов'язаної монети з тим самим номером (тип, випуск, зображення з каталогу). Повторний імпорт оновлює список і показує примірники, яких більше немає у файлі.
- **Список обміну на Numista:** **Вивантажити** для примірників на обмін додає їх у вашу колекцію на Numista з позначкою обміну; примітка для обміну (наприклад *VF-, 50% of price*) стає публічним коментарем. Перенесення примірника між колекцією та обміном у картці змінює позначку й на Numista; імпорт з вашої колекції Numista кладе предмети на обмін у **На обмін**.
- **Список бажаних з uCoin:** **Файл → Імпорт списку бажаних з uCoin (.xlsx)** — вузол **Бажані**, діапазони років (*2008–2026*), зв'язок з Numista без запитів; бажана монета, яка вже є в колекції, — жирним зеленим. В API Numista немає списку бажаних, тож він не вивантажується — у довідці описано, як додати монету до списку бажаних на сайті Numista.
- **Колонка «Обмін»:** скільки у вас на обмін, **✓** — вивантажено на Numista.
- **Видалити позначені** (меню «Колекція» і контекстне меню) — наприклад, увесь список обміну; вивантажені на Numista можна видалити й там або залишити; спочатку робиться копія бази.
- **Колонки:** вирівнювання кожної колонки (праве клацання по заголовку → **Вирівнювання**); «Країна» і «Сюжет» показуються так, як вибрано в меню «Стовпці». Верхній вузол дерева тепер — **Моя колекція**.
- Зрозумілі кнопки в питаннях («Імпортувати й прибрати відсутні», «Залишити на Numista» …) замість «Так / Ні».
