Що перевірити (для тестувальників)

Дякуємо, що тестуєте Coins Collection! Пройдіть ті частини, які стосуються вашої колекції, — усі не обов'язково. Після кожного кроку написано, що ви маєте побачити. Щось інакше — Help → Report a problem/Довідка → Повідомити про проблему (у листі вже є версія та Windows; додайте знімок екрана).

1. Встановлення та перший запуск

  1. Запустіть CoinsCollection-Setup-…exe; інсталятор без підпису — у браузері Зберегти, у SmartScreen Детальніше → Однаково запустити. Очікується: встановлення без прав адміністратора.
  2. Запустіть програму. Очікується: порожня колекція, мова інтерфейсу — як вибрано в інсталяторі (Settings → Language/Налаштування → Мова перемикає її).

2. Імпорт з uCoin

  1. На uCoin перемкніть сайт на English і експортуйте колекцію в Excel (Імпорт з uCoin).
  2. File → Import collection from uCoin (.xlsx).../Файл → Імпорт колекції з uCoin (.xlsx).... Очікується: кількість рядків і помилок, потім країни в дереві ліворуч, монети в списку.
  3. Спробуйте експорт російською чи українською. Очікується: повідомлення, що файл не англійською, і як це виправити; колекцію не змінено.

3. Numista: ключ і зв'язок

  1. Отримайте безкоштовний ключ API і введіть його (Numista: реєстрація та ключ API), Check connection/Перевірити підключення. Очікується: «Підключено: користувач Numista …».
  2. Позначте 10–20 монет однієї країни → Auto-link/Автозв'язок. Очікується: більшість монет отримують номер #Numista, у підсумку — скільки пов'язано і скільки потребують перевірки.
  3. Монета, яка не пов'язалася → праве клацання → Link manually/Пов'язати вручну. Очікується: список типів із фразою пошуку; фразу можна змінити, шукати знову й пов'язати.

4. Ваша колекція на Numista (римські денарії та інші античні монети)

  1. Numista → Import from my Numista collection/Numista → Імпорт з моєї колекції Numista, виберіть емітента (наприклад Roman Empire). Очікується: ваші предмети з роками та станом; після імпорту — монети з зображеннями з каталогу.
  2. Запишіть індекс рідкісності в приватний коментар предмета на Numista, потім Read rarity index/Прочитати індекс рідкісності. Очікується: число в колонці Rarity/Рідкість; сортування за нею ставить найрідкісніші монети першими.
  3. Імпортуйте колекцію Numista, коли монети вже є в програмі з uCoin. Очікується: у колонці In program/У програмі — Пов'язати з … для знайдених монет; якщо нова монета насправді є в програмі — Coin in the program.../Монета в програмі..., виберіть її; другої монети не з'являється.

5. Фото

  1. Відкрийте картку монети (подвійне клацання) і перетягніть свої фото аверсу й реверсу в праву колонку. Очікується: ваші фото поруч із зображеннями з каталогу.
  2. У подробицях монети натисніть ⇄. Очікується: перемикання між вашим фото і зображенням з каталогу.

6. Ціни Numista

  1. Налаштування Numista → What to load from Numista/Що завантажувати з Numista → Numista prices (estimate by condition)/Ціни Numista (оцінка за станом).
  2. Монета з вибраним випуском → праве клацання → Load Numista prices/Завантажити ціни Numista. Очікується: ціна для стану монети в колонці, усі стани — у подробицях.
  3. Пов'язана монета → праве клацання → Auction sales.../Продажі на аукціонах.... Очікується: минулі продажі на аукціонах випуску (або всього типу) з цінами у вашій валюті, підсумок «від — до, медіана», посилання на лоти.

7. Резервна копія

  1. File → Backup collection/Файл → Резервна копія колекції. Очікується: один файл .zip.
  2. (Лише на тестовій копії.) File → Restore from backup/Файл → Відновити з копії. Очікується: колекція й фото — як у копії.

8. Список монет

  1. Праве клацання по заголовку колонки → Columns/Стовпці: сховайте колонку, увімкніть Obverse/Аверс і Reverse/Реверс. Очікується: мініатюри монет у списку; Row height/Висота рядків робить їх більшими.
  2. Перетягніть заголовок колонки на інше місце; змініть розмір вікна, ширину дерева й колонки. Перезапустіть програму. Очікується: усе так, як ви залишили.

Що надіслати разом із проблемою

  • Що ви робили і що сталося — по кроках; знімок екрана з повідомленням.
  • Для помилки імпорту — файл експорту (у ньому лише ваша колекція).
  • Для проблеми з Numista — монету (країна, номінал, рік, номер) і #Numista, який ви очікували.
