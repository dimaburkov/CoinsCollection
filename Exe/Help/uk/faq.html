Питання та проблеми

Монета не знаходиться на Numista або пропонуються не ті типи

Усі типові випадки з рішеннями: Як пов'язати монету — типові випадки.

Змініть фразу пошуку у списку типів і шукайте знову — Numista: зв'язок монет. Перевірте номер у каталозі в картці монети (KM#, Y#, C#). Монети з номером uCoin (UC#) шукаються за фразою — заповніть сюжет.

Монету пов'язано з неправильним типом

Unlink from Numista/Відв'язати від Numista або ще раз Link manually/Пов'язати вручну — Numista: зв'язок монет, розділ «Помилковий зв'язок».

Місячну квоту запитів майже вичерпано

Працюйте з позначеними монетами (один запит на запуск для вивантаження та індексу рідкісності), в автозв'язку виберіть Only link/Лише зв'язати й завантажте характеристики пізніше. Лічильник і квота — на вкладці Requests/Запити налаштувань Numista.

Імпорт: немає колонки 'Country' / файл не англійською

Експорт uCoin зроблено іншою мовою. Перемкніть мову сайту uCoin на English, знову експортуйте колекцію й імпортуйте новий файл — Імпорт з uCoin.

«Unable to write … CoinsCollection.ini»

Файл відкритий у редакторі, який його блокує. Закрийте редактор і повторіть команду.

Фото з Numista не завантажилися

Перевірте підключення до інтернету й ще раз запустіть Update catalogue data/Оновити дані каталогу для позначених монет.

Резервна копія та відновлення

File → Backup collection/Файл → Резервна копія колекції зберігає один файл .zip з базою, усіма фото та налаштуваннями. Зберігайте його на іншому диску або в хмарі. Програма нагадує, якщо копії не було 30 днів.

File → Restore from backup/Файл → Відновити з копії замінює колекцію й фото копією. Поточні дані зберігаються (Db\…before-restore-<час>.bak, Photos\_before-restore-<час>\). Налаштування цього комп'ютера не змінюються.

Крім того, програма робить автоматичні копії бази (Db\*.bak) перед кожним оновленням бази та кожним імпортом.

Питання, пропозиції, проблеми

Help → Report a problem/Довідка → Повідомити про проблему відкриває лист автору з уже заповненими версією програми та Windows — опишіть, що сталося, і додайте знімок екрана. Або пишіть на progua@ukr.net. Питання іншим користувачам і автору — група підтримки в Telegram: t.me/CoinsCol.
