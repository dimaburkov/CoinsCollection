Where to start

Choose the line that describes you. Each way ends with the same result: your collection in the program, linked with the Numista catalogue, with mintage, details and pictures.

1. My collection is on uCoin

  1. On the uCoin website export your collection to Excel (.xlsx) and import the file: Import from uCoin.
  2. That is enough to keep your collection: countries, years, conditions, prices, your photos.
  3. Want mintage, details and catalogue pictures? Register on Numista and get a free API key: Numista: registration and API key. Then Auto-link — linking coins.
  4. Your uCoin collection changed? Export and import it again — Numista links and photos are kept.

2. My collection is on Numista (ancient, Roman, Celtic coins…)

uCoin has no catalogue of ancient coins; Numista has. If you add your coins on Numista:

  1. Register on Numista and get your API key, enter it in Numista → Connect / Settings.
  2. Numista → Import from my Numista collection — choose the issuer (for example Roman Empire), check the items and import: Import (section Import from your Numista collection).
  3. The coins come already linked, with catalogue pictures; year ranges (164–180) and BC years are kept.
  4. Add your own photos in the coin card — next to the catalogue pictures.

Roman denarii (and other ancient coins) without uCoin

You find or collect Roman denarii, and you have no uCoin account? This is way 2, step by step:

  1. Numista account and API key — Numista: registration and API key (about 5 minutes).
  2. Add your denarii on the Numista website. Find the type in the Numista catalogue (emperor, reverse legend), press Add to my collection, choose the grade. You can upload your own photos of the coin there — the program takes them too.
  3. Rarity index. The type page on Numista shows its rarity index (0–100). Write it into the private comment of your item: just the number, for example 97 (or 97;my note).
  4. Import into the program: Numista → Import from my Numista collection, issuer Roman Empire, check the items, Import. New denarii added on Numista later — import again, only the new ones are offered.

What you get in the program:

  • Your photo next to the catalogue picture in the coin card — easy to compare a worn coin with a good catalogue specimen; in the coin details the button ⇄ switches between them.
  • The rarest coins at the top: click the Rarity column header — the list is sorted by the rarity index. Numista cannot sort a collection by rarity.
  • Emperors as periods in the tree on the left, year ranges (164–180), weight, size, references (RIC) in the details; backup of the whole collection in one file.

3. Both: modern coins on uCoin, ancient on Numista

  1. First import from uCoin (way 1).
  2. Then import from your Numista collection (way 2). Coins that are in both are linked, not duplicated.
  3. Later imports from uCoin keep the coins that came from Numista.

4. Neither uCoin nor Numista

Add coins yourself: Collection → Add, and for the next years of the same coin — Add from sample (Ctrl+Ins): only change the year. Periods and currencies are added to the reference lists as you type them. Numista is still useful later: Link manually finds the coin in the catalogue and loads its details and pictures.
