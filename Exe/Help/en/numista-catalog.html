Numista: mintage and type details

For linked coins the program keeps data from the Numista catalogue:

  • Mintage of the issue — the Mintage column (n/a — Numista has no mintage);
  • Type details — composition (the Composition column), weight, size, shape, technique, ruler, series, commemorated topic, years, mints, demonetization (coin details, right column);
  • Photos of the type (Photos).

Update catalogue data

Check coins → Update catalogue data: loads what is missing. Cached answers are free, so a repeated run usually needs 0 requests.

One coin: right-click → Update catalogue data (no cache) — requests the data again (2 requests), for example when a mintage was added on Numista.

Numista prices

Numista estimates the price of an issue for each condition (G, VG, F, VF, XF, AU, UNC). The program can load these estimates:

  1. Turn them on: Numista settings, tab What to load from Numista, Numista prices (estimate by condition); choose the currency (UAH, USD or EUR).
  2. One coin: right-click → Load Numista prices. Many: check coins → Numista prices... — the confirmation shows how many requests are needed.
  • The column Numista, UAH shows the estimate for the condition of your coin; empty — no estimate for this condition (or the issue is not chosen). The coin details show the estimates of all conditions, your condition in [brackets], and the date.
  • 1 request per issue; coins of one issue cost one request. Prices younger than the number of days in the settings (90 by default) are not requested again; for one coin — only prices loaded today are skipped.
  • Only coins with a chosen issue get prices — Choose issue.
  • Prices in another currency stay in the database: switching the currency back shows them again.
