Numista: linking coins

Linking finds the Numista type (#Numista) and issue of a coin. Then the program loads the mintage, the type details and the photos.

One coin — Link manually

Right-click a coin → Link manually (or the Numista menu).

  1. The program searches by the catalogue number (KM#, Y#, C#), then by number and year, then by the search phrase.
  2. If there is one exact result, the coin is linked at once. Otherwise the type list opens.
  3. Choose the issue (year, mint) if it is not found automatically: Choose issue.

Search phrase

If the right type is not in the list, edit Search phrase and press Search (or Enter), for example Ort koronny - Sigismund III Vasa 1623. The phrase you link with is saved in the coin card (Numista search) and used next time.

Historical states

Some coins are listed on Numista under another issuer than the uCoin country (for example Poland 1766 → Polish–Lithuanian Commonwealth). Such results always need your confirmation. When you choose one, the issuer is remembered for the coin's period, and the next coins of that period are found at once.

Many coins — Auto-link

Check coins (Checking coins) → Auto-link. Only unambiguous results are linked; the others are counted in the result — link them manually. The check box Also load type details and photos adds 1 request per coin.
