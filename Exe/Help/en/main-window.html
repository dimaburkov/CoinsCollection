Main window

Navigation tree

On the left: My collection, continents with their countries, No continent, Extinct states, For swap (your swap list, see Import from uCoin) and Checked (all checked coins from any country, see Checking coins). The number in brackets is the number of items. The collection nodes and the totals in the status bar do not include the swap list.

Search

The search field on the toolbar filters the list by country, period, currency, denomination, year, subject, variety, catalogue number, comment and the Numista title (for example Crispina).

Click a column header to sort, click it again to reverse. By default the list is sorted by year, then by denomination.

Right-click a column header: the menu Columns shows or hides columns (the denomination always stays), Row height — normal, medium or large, Default columns — back to the default set. The columns Obverse and Reverse show small photos of the coin: your photo, otherwise the catalogue picture; double-click a photo to open the photo viewer. Drag a column header with the mouse to move the column (the check box column always stays first). Alignment — left, center or right for the column under the mouse. The choice, the order and the alignment are remembered.

The program remembers the size and position of the window, the width of the country tree, the height of the details and the column widths you set with the mouse; Default columns also resets the column widths and alignment.

All columns fit into the window: if they do not, the text columns (country, period, currency, denomination, subject, composition) get narrower, long text ends with “…” (the full text is in the coin details). A column whose width you changed with the mouse keeps your width.

Coin details

Under the list: obverse and reverse photos (double-click — photo viewer) and the coin data in two columns. The #Numista value is a link to the type page on Numista. The right column shows the type details loaded from Numista (weight, size, shape, ruler, series, years, mints, demonetization). With Numista prices on — the row Numista prices.

Status bar

Number of shown items, their quantity and value, and the number of checked items. With Numista prices on — the Numista estimate of the shown coins (estimate × quantity) and how many of them have no estimate.
