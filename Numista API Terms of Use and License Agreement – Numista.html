1. Definitions

“API” means the Numista application programming interface, including its endpoints, authentication mechanisms and documentation.

“API Credentials” means API keys, access tokens, client secrets and other credentials used to access the API.

“Catalogue Data” means numismatic catalogue information supplied through the API, including information about coins, banknotes, tokens, medals, issuers, mints, catalogues, types and related records.

“Catalogue Metadata” means data returned by the following endpoints, or by replacement endpoints providing equivalent information:

  • /catalogue/issuers;
  • /catalogue/mints;
  • /catalogue/{mint_id};
  • /catalogue/catalogues.

“End User” means a person who uses an application, website or service operated by the Licensee.

“Licensed Data” means Catalogue Data, User Collection Data and any other information supplied through the API.

“Normal Search” means a catalogue search request made through the endpoint /types.

“N#” means the unique Numista identifier assigned to a numismatic type, displayed in the form “N#12345”.

“Personal Project” means a private and non-commercial project used by an individual for their own numismatic activities and not made available to the general public, customers or members of an organisation.

“Search by Image” means a request that searches the Numista catalogue using one or more images through the endpoint /search_by_image.

“Successful Request” means an API request that is successfully processed and returns the requested result. A request that returns an error response is not a Successful Request.

“Sales Records Request” means a request to retrieve the detailed Catalogue Data for past sales records through the endpoint /types/{type_id}/sales_records, or through a replacement endpoint providing equivalent information.

“Type Detail Request” means a request to retrieve the detailed Catalogue Data for a specific numismatic type through the endpoint /types/{type_id}, or through a replacement endpoint providing equivalent information.

“User Collection Data” means collection, inventory, wish-list, swap-list or other account-related information concerning a Numista user.

5. Free Plan

The Free Plan provides access to all API functionality except Search by Image. It includes up to 2,000 API requests per calendar month.

Unused requests do not carry forward to the following month.

Numista may reject further requests once the monthly quota has been reached.

6. Paid Plan pricing

6.1 Activation fee

Activation of the Paid Plan is subject to a one-time fee of €100 excluding VAT.

The activation fee is non-refundable after the Paid Plan has been activated, except where a refund is required by law.

6.2 Successful requests

Only Successful Requests are charged under the Paid Plan and counted toward the monthly pricing tiers.

Requests that return an error response are not charged and do not count toward the monthly pricing tiers.

6.3 Search by Image

Search by Image requests are charged according to the following progressive monthly tiers:

Monthly volume Price per request, excluding VAT
First 20,000 requests €0.030
Requests 20,001 to 50,000 €0.024
Requests above 50,000 €0.018

Each rate applies only to the requests falling within the corresponding tier.

6.4 Normal Search

Normal Search requests are charged according to the following progressive monthly tiers:

Monthly volume Price per request, excluding VAT
First 20,000 requests €0.015
Requests 20,001 to 50,000 €0.012
Requests above 50,000 €0.009

Each rate applies only to the requests falling within the corresponding tier.

Only the first page of a Normal Search is charged. Retrieving page 2 or any subsequent page of the same search results is free of charge and do not count toward the pricing tiers.

6.5 Sales records

Sales Records Requests are charged €0.010 per request.
As an exception, if Numista is not able to return any sales records for the required type, no fee is charged for the request.

6.6 Other API operations

API operations other than Search by Image, Normal Search, and Sales Records Requests are not individually charged, unless otherwise agreed in writing.

They remain subject to the Type Detail Request limit, technical limits, anti-abuse measures and this agreement.

6.7 Type Detail Request limit

The Licensee may make no more than 15 Type Detail Requests for each successful Normal Search or Search by Image request .

This limit is calculated cumulatively from the beginning of the calendar month.

At any time, the number of successful Type Detail Requests made since the beginning of the previous calendar day must not exceed 15 times the number of successful Normal Search and Search by Image requests made during the same period.

For example, if 100 successful searches have been made since the beginning of the calendar month, no more than 1,500 successful Type Detail Requests may be made during that period.

Requests that return an error are not included in this calculation. Numista may reject Type Detail Requests when the limit has been reached.

6.8 Monthly minimum

Except during the first calendar month in which the Paid Plan is active, the Paid Plan is subject to a minimum monthly charge of €100 excluding VAT.

Where usage-based charges are below €100, the Licensee will be charged €100.

Where usage-based charges exceed €100, the Licensee will be charged the actual usage-based amount.

All prices are stated excluding VAT.

Numista charges VAT at the current French standard rate, presently 20%, to:

Companies established outside France are not charged VAT, provided that they supply the business and tax information reasonably required by Numista to establish their status.
